# Pembagian Tugas Tim Pengembang CariKos

Dokumen ini memuat matriks pembagian tugas pengembangan aplikasi web CariKos untuk tim yang terdiri dari 4 orang pengembang. Seluruh ruang lingkup pekerjaan dibagi secara sama rata (*equal workload*) tanpa adanya hierarki atau peran senior/junior.

## Standar Kualitas Teknis & Definisi Selesai (DoD Global)

Setiap anggota tim wajib mematuhi standar berikut sebelum sebuah tugas dinyatakan selesai:
1. **Fungsional**: Fitur terhubung dengan endpoint backend terkait dan menangani skenario sukses maupun gagal (*error handling*).
2. **Desain & Responsif**: Mengikuti tema CariKos (aksen kuning amber dan neutral dark) serta nyaman digunakan di layar desktop maupun ponsel.
3. **Kompilasi Bersih**: Menjalankan perintah `npm run build` di folder `frontend` tanpa kegagalan build, syntax error, atau hydration mismatch.
4. **Git Workflow**: Bekerja pada branch fitur masing-masing (`feature/nama-fitur`) dan digabungkan ke branch `develop` melalui Pull Request setelah di-review oleh rekan tim.
